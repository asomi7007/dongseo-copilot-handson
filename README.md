# 동서석유화학 동서 Copilot 실습 자료

정적 페이지로 게시하는 핸즈온 자료입니다. 페이지 본문과 실습 파일은 비밀번호로 암호화되어 있어,
첫 화면에서 비밀번호를 입력해야 열립니다. (AES-GCM, PBKDF2-SHA256)

- `index.html` : DAY1 암호 입력 화면으로 이동하는 시작 페이지
- `day1.html` : 동서석유화학 Copilot 핸즈온 · DAY 1 (실습 워크북)
- `day1-deck.html` : 동서석유화학 Copilot 핸즈온 · DAY 1 · 설명 발표 (발표 장표)
- `day2.html` : 동서석유화학 Copilot 핸즈온 · DAY 2 (실습 워크북)
- `day2-deck.html` : 동서석유화학 Copilot 핸즈온 · DAY 2 · 설명 발표 (발표 장표)
- `kit/*.enc` : 암호화된 실습 파일 (워크북 안의 다운로드 버튼으로 받습니다)

모든 페이지는 같은 비밀번호와 같은 키를 쓰므로, 한 페이지에서 입장하면 같은 탭의 다른 페이지는 다시 묻지 않습니다.
원문 편집과 다시 빌드는 작성자 로컬 원본에서 build.py로 수행합니다.

> **보안 안내:** 이 정적 사이트의 비밀번호는 브라우저에서 복호화하는 게이트이며 GitHub 계정 인증이나 접근 제어가 아닙니다. 암호문과 첨부 암호문은 누구나 내려받을 수 있고, 짧은 비밀번호는 오프라인 추측 공격에 취약합니다. 이 배포에는 교육용 가상 자료만 포함하며 실제 기밀 자료에는 사용하지 마세요.
